# My Future Pet admin

## Platform
web

## Users and purpose
Shelter staff and system administrators manage rescue pets, adoption reviews, appointments, community posts, notifications, reports, people and audit logs. Authentication uses the existing Supabase flow.

## Confirmed constraints
Orange-and-white branding, existing product logo and Jagna Animal Lover and Rescue Group identity. No interactive dashboard preview on sign-in. Preserve the existing authentication and management functions. No live test submissions.

## Responsive sign-in agreement
On 2026-10-20 the user approved a compact phone experience: sign-in first, compact shelter identity below; fuller branded panel on desktop. Touch and keyboard controls must remain available. The mobile app is a separate Flutter project.

## Public website agreement — 2026-10-20
User approved a full photography-led public landing page aimed at shelter staff/admins, with licensed illustrative stock photography, restrained interaction, orange-and-white branding and a dedicated /sign-in view. The root remains the authenticated dashboard for authorized signed-in users. No live test submissions or production deployment in this milestone.
